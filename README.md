**Doriku** connects your AI coding tools with your team's workflow.<br/>
One command to sync tasks across **Claude Code**, **MCP servers**, and your entire dev team.

</div>

<br/>

## How It Works

\`\`\`
You (Claude Code)  <-->  Doriku API  <-->  Your Team
        |                    |                  |
   MCP Server          Task Sync          Dashboard
   Auto Hooks        Real-time         Collaboration
\`\`\`

<br/>

## Get Started in 30 Seconds

\`\`\`bash
npx @doriku/cli setup
\`\`\`

Enter your API key, and you're connected. That's it.
